      C5 note — flash from a terminal if the browser fails

# The ESP32-C5 USB-Serial/JTAG can drop
# when the browser loads the flash stub.
# If Install fails, flash with esptool:
esptool --chip esp32c5 --no-stub \
  write-flash 0x0 Piglet.ino.merged.bin

      

        After installing from the browser, the board's USB auto-reset into bootloader mode can get
        stuck (the board itself is fine and boots normally). If a later Arduino IDE/esptool upload
        fails to connect, hold BOOT, tap RESET,
        release BOOT, then try again.
